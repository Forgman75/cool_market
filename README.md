# SkyStore — интернет-магазин

**SkyStore** — учебный проект интернет-магазина, разработанный с использованием Python и Django.

Проект демонстрирует создание веб-приложения на Django, работу с URL-маршрутами, представлениями, HTML-шаблонами, статическими файлами и обработку POST-запросов.

## Технологии

В проекте используются:

- **Python 3.12** — язык программирования.
- **Django 6.1.3** — веб-фреймворк.
- **HTML5** — разметка веб-страниц.
- **CSS3** — оформление страниц.
- **Bootstrap 5.3.3** — адаптивная вёрстка и компоненты интерфейса.
- **Bootstrap Icons** — иконки интерфейса.

## Возможности проекта

На текущем этапе реализованы следующие возможности:

- Главная страница интернет-магазина.
- Страница контактов с информацией о компании.
- Форма обратной связи.
- Обработка данных формы методом POST.
- Защита формы от CSRF-атак с помощью встроенного механизма Django.
- Вывод уведомления об успешной отправке сообщения.
- Перенаправление пользователя после отправки формы (Post/Redirect/Get).
- Использование пространства имён URL-маршрутов приложения.

## Установка и запуск

### 1. Клонирование проекта

```bash
git clone <ссылка-на-репозиторий>
```

Перейдите в папку проекта:

```bash
cd cool_market
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация виртуального окружения

Для Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Для Windows CMD:

```cmd
.venv\Scripts\activate.bat
```

### 4. Установка Django

```bash
python -m pip install Django==6.1.3
```

### 5. Применение миграций

```bash
python manage.py migrate
```

### 6. Запуск сервера разработки

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

http://127.0.0.1:8000/

| Страница | URL | Назначение |

| Главная | `/` | Главная страница SkyStore |
| Контакты | `/contacts/` | Контактная информация и форма обратной связи |

## Обработка формы обратной связи

На странице контактов расположена форма со следующими полями:

- `name` — имя пользователя;
- `phone` — номер телефона;
- `message` — текст сообщения.

Форма отправляет данные методом POST.

Для защиты от CSRF-атак используется встроенный тег Django:

```django
{% csrf_token %}
```

После получения данных представление `contacts` обрабатывает запрос, выводит полученную информацию в консоль и формирует уведомление с помощью Django Messages.

Для перенаправления используется именованный маршрут:

```python
return redirect('catalog:contacts')
```

Такой подход реализует паттерн **Post/Redirect/Get (PRG)** и предотвращает повторную отправку формы при обновлении страницы.

> На текущем этапе данные формы выводятся в консоль сервера. Сохранение сообщений в базе данных и отправка уведомлений по электронной почте пока не реализованы.

## URL-маршрутизация

Маршруты приложения находятся в `catalog/urls.py`.

Для приложения задано пространство имён:

```python
app_name = 'catalog'
```

Это позволяет обращаться к маршрутам с указанием имени приложения:

```django
{% url 'catalog:home' %}
{% url 'catalog:contacts' %}
```

## Статические файлы

CSS-файл расположен в каталоге:

```text
catalog/static/css/styles.css
```

Для подключения статических файлов в HTML-шаблонах используется тег Django:

```django
{% load static %}
```

Подключение таблицы стилей:

```django
<link rel="stylesheet" href="{% static 'css/styles.css' %}">
```
